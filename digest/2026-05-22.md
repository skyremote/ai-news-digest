# AI News Digest — 2026-05-22

## Executive Summary

Google I/O dominated the last 24 hours: Gemini 3.5 Flash is now the default engine in AI Mode globally, and Google is replacing the query box with persistent agents that run continuously on Cloud VMs to track user objectives. Simultaneously, Trump pulled a pre-release AI model-evaluation executive order hours before signing after Musk, Zuckerberg, and Sacks lobbied against it — signalling that US AI governance will remain industry-led for the foreseeable future. In a quieter development with large downstream consequences, Spotify and Universal Music established the first major consent-credit-compensation framework for AI-generated music at commercial scale.

Gemini 3.5 Flash goes global as AI Mode's default model, outperforming Gemini 3.1 Pro on coding and agentic benchmarks at four times the output speed; more significantly, Google announced "information agents" that run continuously on Cloud VMs, building personalised dashboards against standing user objectives rather than answering discrete queries. *— [Google Blog](https://blog.google/innovation-and-ai/technology/ai/google-io-2026-all-our-announcements/), [TechCrunch](https://techcrunch.com/2026/05/19/with-gemini-3-5-flash-google-bets-its-next-ai-wave-on-agents-not-chatbots/)*

The two companies signed landmark recorded-music and publishing agreements giving Spotify Premium subscribers a paid tool to create AI covers and remixes, with explicit artist consent, on-label attribution, and revenue sharing — the first such structure from a major label at commercial scale. *— [Spotify Newsroom](https://newsroom.spotify.com/2026-05-21/universal-music-group-spotify-licensing-agreements-fan-made-covers-remixes/), [Variety](https://variety.com/2026/digital/news/spotify-universal-music-licensing-agreements-fan-made-covers-1236755951/)*

## Signal, Not Noise

**Google's persistent information agents are the real story from I/O.**
Every other announcement this week was incremental. The information agent — a process that runs continuously on a Cloud VM, monitors standing objectives ("tell me when flights to Tokyo drop below $600"), and delivers structured updates rather than waiting for a query — is a different computing model. It inverts the relationship between user and search engine: instead of the user initiating, the agent maintains state and surfaces conclusions on its own schedule. The infrastructure implication is that Google is positioning Cloud as the execution layer for ambient intelligence, not just hosting. That is a meaningful moat if it works — and a reason Exa's investors are betting $250M that there is still an independent retrieval layer to be won before Google locks it in.

*— [Google Search I/O 2026 blog](https://blog.google/products-and-platforms/products/search/search-io-2026/)*
