## Signal, not noise

**[Anthropic VirBench: deterministic tools push biology AI accuracy from 16.9% to 92.8%](https://www.anthropic.com/science)** — *Anthropic*

The finding is not that Claude got better at biology; it is that the databases biologists use were built for humans clicking through web interfaces, not for agents issuing API calls at scale. Wrapping NCBI's REST endpoints in a single deterministic tool erased almost all of the accuracy deficit. In three months this pattern — purpose-built tool shims between frontier models and domain data stores — will be the standard deployment architecture for AI in science, pharma, and any field where ground truth lives in an authenticated, rate-limited database. The model capability race matters less here than whoever owns the tool layer.
