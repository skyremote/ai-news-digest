## Executive Summary

The inference-speed race escalated this week: Cerebras-backed wafer-scale silicon now runs GPT-5.6 Sol at 750 output tokens per second through the OpenAI API, compressing a 2,500-question graduate-level benchmark to eleven hours. Two Apache 2.0 open-weight models — Meta's Muse Glimmer and Alibaba's Qwen3.8-27B — shipped within four days of each other, both sized for a single consumer GPU and built for agentic workloads, raising the open-weight floor to near-frontier capability. A Black Hat disclosure showed that a zero-privilege GitHub issue executes code on Anthropic's and Google's own CI runners, making AI coding agents in automated pipelines the fastest-growing attack surface of 2026.

## Top 5 Stories

**Cerebras powers GPT-5.6 Sol Ultrafast at 750 output tokens per second**

Wafer-scale on-chip SRAM eliminates the memory-bandwidth bottleneck that limits GPU inference; the resulting 14x throughput gain compresses a 2,500-question graduate-level benchmark to eleven hours at accuracy comparable to Claude Fable 5.

*—[Cerebras](https://www.cerebras.ai/blog/accelerating-gpt-5-6-sol-ultrafast-with-openai)*

**Zero-privilege GitHub issue gave CI runner access to anyone targeting Claude Code and Gemini CLI**

A crafted GitHub issue from an unprivileged account was sufficient to execute code on Anthropic's and Google's own coding-agent CI runners (Claude Code's allowlist validator stripped single-quoted strings before its 23 checks ran; Gemini CLI's container launcher carries CVSS 10.0, CVE-2026-12537); a follow-on Claude Code bypass exfiltrated an API key one character at a time via HuggingFace's public download counter as a covert channel (CVE-2026-54316).

*—[Novee Security](https://novee.security/blog/critical-flaws-in-anthropic-google-and-openais-coding-agents/) / [The Hacker News](https://thehackernews.com/2026/08/claude-code-and-gemini-cli-flaws-let.html)*

**DeepSeek V4-Pro exits preview with adaptive reasoning; off-peak API pricing takes effect**

V4-Pro-0813 reached general availability on 13 August with configurable reasoning modes (low / standard / max) and native OpenAI Responses API support; as of 16:00 UTC Sunday, DeepSeek's new rate schedule prices off-peak inference at exactly half the peak rate.

*—[DeepSeek API docs](https://api-docs.deepseek.com/news/news260813/)*

**Meta Muse Glimmer and Qwen3.8-27B both ship Apache 2.0 within a week**

Meta's 29.6B Muse Glimmer (131K context, local agentic tool use, 10 Aug) and Alibaba's 27.78B Qwen3.8 (262K native context extensible to 1M, interleaved text-image-video, Gated DeltaNet architecture, 14 Aug) landed under Apache 2.0 within four days, both sized to run on a single consumer GPU and both targeting agentic workloads teams currently pay closed-API rates for.

*—[Meta AI Research](https://research.meta.ai/blog/introducing-muse-glimmer-open-agentic-model)*

**EU AI Act transparency rules go live: AI systems must now identify themselves across Europe**

Phase 2 provisions of the EU AI Act are in effect: any AI system deployed in Europe that generates text, image, audio, or video and could be mistaken for a human is legally required to identify itself — the first continent-wide legally binding disclosure requirement of its kind.

*—European Commission*

## Signal-Not-Noise

**DeepSeek's time-of-day API pricing is the most underreported structural signal of the week.**

Coverage of V4-Pro's GA fixated on reasoning modes and benchmark gains; the pricing footnote — off-peak costs exactly half the peak rate, effective Sunday — is the more durable development. Inference cost now has a time dimension the way electricity does, and any batch-tolerant workload (nightly evaluations, document processing pipelines, embedding refreshes, LLM-as-judge runs) can cut compute spend in half by scheduling to off-hours. This pricing structure will spread to other providers as inference markets mature; pipelines designed today without time-aware cost routing will need retrofitting tomorrow.
