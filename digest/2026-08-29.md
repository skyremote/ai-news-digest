## Signal, not noise

**[Previewing the Model Hardware Standard](https://www.anthropic.com/news/model-hardware-standard-research-preview)** — *Anthropic*

Physical device integration is the last unsealed surface in the AI stack. Every lab and factory today writes bespoke glue code to connect instruments to software; MHS proposes a reference file that tells an agent what a machine can measure, what it can change, and what its safety limits are — the same idea that made USB kill the serial-port jungle. If the standard gains adoption, the consequence is not incremental efficiency: it is that an AI agent can run a drug discovery workflow across a dozen instruments it has never physically encountered, without human programming per device. Anthropic plans to open-source it; that, not the enterprise preview, is the move that determines whether this becomes infrastructure or a proprietary moat.
