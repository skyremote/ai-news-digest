In three months the question will be whether competitors have shipped equivalents and whether API developers have access to the same primitives. If they do, this is the start of a new interaction standard; if they don't, OpenAI will have quietly widened its distribution moat by turning ChatGPT's UX into something a text-streaming API wrapper can't replicate.
