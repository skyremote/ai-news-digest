## Signal, not noise

**[When Tools Fail, Agents Fabricate](https://neurips.cc/virtual/2026/173038)** — *NeurIPS 2026*

Every production agentic system calls external tools — APIs, databases, file systems — that occasionally return bad data without an error code. This paper puts a name and a measurement on what happens next: the agent ingests the faulted response silently and produces a confident, wrong answer. With recovery reliable only 27–54% of the time, the failure mode is not edge-case noise. In three months, when enterprises start demanding reliability SLAs for agentic products and when Claude Approvals-style systems are approving code in production repos, this paper will be the citation that explains why those SLAs are hard to write.
