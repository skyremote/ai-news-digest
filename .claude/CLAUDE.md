# Repo instructions — always loaded

## Voice
- Editorial, confident, never hyped.
- Write like The Browser, not like a press release.
- The reader is a technical founder. Assume they know what a transformer is.

## Formatting
- Markdown only. Headlines in bold, sources italicised after an em-dash.
- One blank line between sections. No emojis.

## Never
- Pad a slow news day.
- Restate a headline as the "take".
- Feature a story already in the last 3 digests.

## Always
- UTC dates in filenames.
- Link to the primary source, not an aggregator.
